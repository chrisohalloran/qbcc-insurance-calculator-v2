This page shows the current QBCC home warranty insurance premium table used by the QBCC insurance calculator. The tables are for Queensland residential building work and are based on the official premium schedule effective from 1 July 2020, verified current for 2026 in this content set.

Use the table to check the GST-inclusive insurance premium for common project values, then add the separate QLeave levy where it applies. For an exact estimate at any value, including values between the rows shown here, use the calculator.

How to read the QBCC premium table

QBCC premiums are based on the insurable value of the work. That usually means the contract value including labour, materials and GST. If the value falls between table rows, the premium is rounded up to the next $1,000 row. For example, a $300,250 project uses the $301,000 premium.

The premium itself is GST-inclusive. It does not include the QLeave levy, builder margin, contract administration charges or any project-specific allowance your contractor may add.

Worked example: $300,000 project

For a $300,000 new construction project, the QBCC premium row is $2,102.10. If the same dollar value is a renovation, the QBCC premium is $3,629.65. The renovation premium is $1,527.55 higher at that value.

The QLeave levy is separate. On a $300,000 GST-inclusive contract, the GST-exclusive value is approximately $272,727.27. Applying the 0.575% QLeave rate gives a levy estimate of $1,568.18. That makes the combined premium and levy approximately $3,670.28 for new construction or $5,197.83 for renovation.

For a shareable calculation, open the $300,000 new construction estimate or enter your own value in the QBCC insurance calculator.

QLeave levy is separate

The QLeave levy is not part of the QBCC insurance premium table. It is generally charged at 0.575% of the GST-exclusive cost of building and construction work where the project is above the QLeave threshold. Builders should treat it as a separate line item when pricing a project.

This matters because a quote can be correct on the QBCC premium and still miss the QLeave allowance. For higher value work, check both the insurance premium and the levy before finalising the contract. The QBCC insurance costs guide explains how these amounts fit into project pricing.

Common premium table mistakes

  • Using the new construction table for an extension or alteration to an existing home.
  • Forgetting that values above a $1,000 threshold round up to the next row.
  • Comparing a GST-exclusive quote against a GST-inclusive premium table value.
  • Assuming the QLeave levy is already included in the QBCC premium.
  • Using old saved copies of a premium table without checking the current calculator rate.

When to use the calculator instead

The tables above are useful for fast checking, but most contracts do not land exactly on the round values shown. Use the calculator when your value is between rows, when you want the QLeave estimate included, or when you need to compare new construction and renovation side by side.

Frequently asked questions

What is the current QBCC premium table for 2026?

The current table used here is the QBCC premium schedule effective from 1 July 2020, verified current for 2026 in this content set. The amounts shown are GST-inclusive insurance premiums.

Which QBCC premium table should I use?

Use the new construction table for a new residence or knockdown-and-rebuild. Use the renovation table for alterations, additions, repairs, pools and work on an existing home.

Does the QBCC premium include the QLeave levy?

No. The QLeave levy is separate from the QBCC home warranty insurance premium. Check both amounts before finalising a quote or contract.
